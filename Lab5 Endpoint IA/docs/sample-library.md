# Bitácora de Zephyr

Este es un documento ficticio para probar la biblioteca de AdanGPT.

El dragón Zephyr vive en la montaña de obsidiana. Tiene escamas azules y sus alas brillan cuando amanece. Su comida favorita son las moras de cristal.

Zephyr protege una biblioteca con tres salas: Historia, Ciencia y Magia. La biblioteca abre de lunes a viernes de 9:00 a 17:00. Los sábados abre de 10:00 a 14:00 y los domingos permanece cerrada.

Para solicitar un libro, el visitante debe indicar el título en la mesa de recepción. El préstamo dura siete días y puede renovarse una vez si nadie más reservó el libro.
